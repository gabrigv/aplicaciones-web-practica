# A5. Caza los errores de la galería

## Errores encontrados

1. `<img>src="playa.jpg" ...` → los atributos están **fuera** de la etiqueta; deben ir dentro de `<img ...>`.
2. `</img>` → `<img>` **no tiene etiqueta de cierre**.
3. `style="width=300px; height=200px;"` → en CSS se usan **dos puntos (`:`)**, no `=`. Correcto: `width: 300px; height: 200px;`
4. La segunda imagen (`monte.jpg`) **no tiene atributo `alt`**.
5. `href=https://www.wikipedia.org` → el valor del atributo debe ir **entre comillas**.
6. El enlace `<a>` **no está cerrado** con `</a>`.
7. (Mejora) Falta el atributo `lang="es"` en `<html>`.

## Versión corregida

```html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <title>Mi galería</title>
</head>
<body>
  <h1>Mi viaje de fin de curso</h1>
  <img src="playa.jpg" alt="Playa al atardecer">
  <img src="monte.jpg" alt="Vista del monte" style="width: 300px; height: 200px;">
  <a href="https://www.wikipedia.org" target="_blank">Más información sobre el destino</a>
</body>
</html>
```
