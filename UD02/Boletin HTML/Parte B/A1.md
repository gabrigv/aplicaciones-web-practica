# A1. Verdadero o falso (corrige las falsas)

| N.º | Afirmación | V / F | Corrección |
|-----|------------|-------|------------|
| 1 | "La etiqueta `<img>` se cierra con `</img>`." | **F** | `<img>` es una etiqueta vacía: no tiene etiqueta de cierre. |
| 2 | "El atributo `alt` muestra un texto si la imagen no se puede cargar." | **V** | |
| 3 | "Para dar ancho y alto a una imagen se recomienda usar `style` en lugar de `width` y `height`." | **V** | |
| 4 | "La propiedad `float` permite que una imagen flote a la izquierda o a la derecha del texto, o que no flote." | **V** | |
| 5 | "El rótulo de un enlace solo puede ser un texto." | **F** | El rótulo puede ser un texto, una imagen o cualquier otro elemento HTML (o una mezcla). |
| 6 | "`target="_blank"` hace que el enlace se abra en una ventana (pestaña) nueva." | **V** | |
| 7 | "Por defecto, un enlace ya visitado se ve azul y uno por visitar, morado." | **F** | Es al revés: el enlace por visitar se ve **azul** y el ya visitado, **morado**. |
| 8 | "Un enlace relativo escribe la URL completa, incluido el dominio." | **F** | Eso es un enlace **absoluto**. El relativo indica la ruta respecto a la página actual, sin dominio. |
