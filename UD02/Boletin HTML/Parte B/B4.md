# B4. Mis enlaces favoritos

## Codigo

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>B4 - Mis enlaces favoritos</title>
</head>
<body>
  <h1>Mis enlaces favoritos</h1>

  <p><a href="https://www.w3.org/">W3C (se abre en la misma ventana)</a></p>

  <p><a href="https://www.google.com/" target="_blank">Google (se abre en ventana nueva)</a></p>

  <p><a href="https://www.youtube.com/" target="_blank" style="color: red;">YouTube (ventana nueva y en color rojo)</a></p>
</body>
</html>
```

## Pregunta: ¿De qué color se ve por defecto un enlace por visitar y uno ya visitado?
- Enlace por visitar: **azul** y subrayado.
- Enlace ya visitado: **morado** y subrayado.
