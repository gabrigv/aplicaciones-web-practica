# A6. Rutas que no funcionan

Estructura del proyecto:

```
proyecto/
├── index.html
├── contacto.html
├── apuntes.pdf
└── imagenes/
    ├── logo.png
    └── equipo.jpg
```

| Código | ¿Funciona? | Motivo | Corrección |
|--------|-----------|--------|------------|
| `<img src="logo.png" alt="Logo">` | ❌ No | `logo.png` está dentro de `imagenes/` | `<img src="imagenes/logo.png" alt="Logo">` |
| `<img src="imagenes/equipo.jpg" alt="Equipo">` | ✅ Sí | | |
| `<a href="Contacto.html">Contacto</a>` | ❌ No | El archivo es `contacto.html` en minúsculas (el servidor distingue mayúsculas) | `<a href="contacto.html">Contacto</a>` |
| `<a href="apuntes.pdf">Apuntes</a>` | ✅ Sí | | |
| `<a href="imagenes/apuntes.pdf">Apuntes</a>` | ❌ No | `apuntes.pdf` está en la carpeta principal, no en `imagenes/` | `<a href="apuntes.pdf">Apuntes</a>` |
| `<img src="imagenes/equipo.png" alt="Equipo">` | ❌ No | La extensión es `.jpg`, no `.png` | `<img src="imagenes/equipo.jpg" alt="Equipo">` |
