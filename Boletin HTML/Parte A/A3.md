# A3. Caza los errores

## Errores encontrados

1. Falta `<!DOCTYPE html>` al principio del documento.
2. Falta `<meta charset="utf-8">` dentro de `<head>` (y el `meta author`).
3. La etiqueta `<title>` no está cerrada (falta `</title>`).
4. El `<h1>` se abre con `<h1>` pero se cierra con `</h2>`.
5. Anidación incorrecta: `<b>` se abre dentro de `<p>` pero se cierra después de `</p>`. Hay que cerrar primero `</b>` y luego `</p>`.

## Código corregido

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="utf-8">
    <meta name="author" content="Adrián Villena">
    <title>Mi tienda de gadgets</title>
</head>
<body>
    <h1>Ofertas de otoño</h1>
    <p>Auriculares con <b>cancelación de ruido</b></p>
</body>
</html>
```
