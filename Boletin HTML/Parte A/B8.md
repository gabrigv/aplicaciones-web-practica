# B8. Etiquetas anidadas: el mensaje urgente

## Codigo

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="descripcion" content="Plantilla base para el boletin de 2.º SMR">
    <meta name="autor" content="Gabriel">
    <title>Plantilla de 2.ºSMR</title>
</head>
<body>
    <p>
        <b><i><u>¡Alerta de seguridad: no abras el correo de remitentes desconocidos!</u></i></b>
    </p>
    <p>
        <b><i><u>¡Alesta de seguridad</b> no abras el correo de remitentes desconocidos!</u></i>
    </p>
</body>
</html>
```

## ¿Cuál es la secuencia de cierre y por qué?

Si se abre en el orden `<b> <i> <u>`, se cierra al revés: `</u> </i> </b>`.

Las etiquetas se cierran en orden inverso a como se abren: la última que se abre es la primera que se cierra, como si fueran cajas una dentro de otra.

## ¿Qué hace el navegador con la versión mal cerrada?

El navegador intenta arreglar el error por su cuenta y cierra y vuelve a abrir etiquetas como le parece. Por eso los estilos se cortan o se alargan donde no deberían y el resultado no es el esperado. Además, el código no pasa el validador del W3C.
