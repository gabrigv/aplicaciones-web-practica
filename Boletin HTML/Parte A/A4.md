# A4. Estilos rotos

## Línea 1

```html
<h1 style="color:red font-size:40px;">Directo esta noche</h1>
```

**Fallo:** falta el `;` entre `color:red` y `font-size:40px`. Cada par propiedad:valor debe terminar en `;`.

```html
<h1 style="color:red; font-size:40px;">Directo esta noche</h1>
```

## Línea 2

```html
<p style="text-align=center;">Estreno de temporada</p>
```

**Fallo:** la propiedad y el valor se separan con `:` y no con `=`.

```html
<p style="text-align:center;">Estreno de temporada</p>
```

## Línea 3

```html
<p style="background-color:yellow;">Sorteo de una tarjeta gráfica<p>
```

**Fallo:** el párrafo no se cierra: al final pone `<p>` en vez de `</p>`.

```html
<p style="background-color:yellow;">Sorteo de una tarjeta gráfica</p>
```
