# A5. Comentarios y anidación

## Errores

1. **Comentario mal escrito:** se abre con `<!-` y se cierra con `->`. Lo correcto es `<!--` para abrir y `-->` para cerrar.
2. **Anidación incorrecta:** se abre `<strong>` y luego `<em>`, así que hay que cerrar primero `</em>` y después `</strong>` (la última que se abre es la primera que se cierra).

## Código corregido

```html
<!-- Revisar el texto antes de publicar -->
<p>Tu contraseña debe tener <strong><em>al menos 12 caracteres</em></strong>.</p>
```
