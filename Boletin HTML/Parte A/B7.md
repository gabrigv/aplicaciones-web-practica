## ¿Qué diferencia hay entre <span> y <p> para destacar parte de un texto?

- `<p>` es un elemento de bloque: crea un párrafo nuevo que empieza en otra línea y ocupa todo el ancho.
- `<span>` es un elemento en línea: no hace saltos de línea, así que sirve para dar estilo solo a una palabra o frase dentro de un párrafo.

Por eso, para destacar parte de un texto se usa `<span>`. Con `<p>` se rompería la frase en varias líneas.
