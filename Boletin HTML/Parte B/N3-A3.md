# A3. Reflexiona

**1. ¿En qué tipo de páginas resulta más útil un índice con bookmarks?**
En páginas **largas** con muchas secciones, en las que hay que hacer mucho scroll: guías, manuales, tutoriales, apuntes, artículos largos, preguntas frecuentes (FAQ), wikis, etc.

**2. ¿A qué id debe apuntar el enlace de vuelta y dónde tienes que ponerlo?**
Debe apuntar al id del principio de la página, donde está el índice (por ejemplo `<a href="#inicio">Volver arriba</a>`). El atributo `id="inicio"` se pone en el elemento de arriba del todo (por ejemplo `<h1 id="inicio">` o en el propio índice), y el enlace "Volver arriba" se coloca **al final de cada sección**.

**3. ¿Qué pasaría si dos secciones tuvieran el mismo id?**
El HTML no sería válido y el enlace saltaría solo a la **primera** sección con ese id; a la segunda no se podría llegar con el enlace.
