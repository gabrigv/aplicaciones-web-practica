# B3. ¿Qué formato elijo?

## Codigo

```html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <title>B3 ¿Qué formato elijo?</title>
</head>
<body>
  <h1>¿Qué formato de imagen elijo?</h1>

  <p>Para una foto de vacaciones con muchos colores el formato recomendado es
  <strong>JPEG (.jpg)</strong>, porque comprime muy bien las fotografías.</p>
  <img src="descargas/paisaje.jpg" alt="Foto de un paisaje en JPG" style="width: 250px;">

  <p>Para un logo con fondo transparente el formato recomendado es
  <strong>PNG (.png)</strong>, porque admite transparencia y no pierde calidad.</p>
  <img src="descargas/logo.png" alt="Logo con fondo transparente en PNG" style="width: 150px;">

  <p>Para un icono que se vea nítido a cualquier tamaño el formato recomendado es
  <strong>SVG (.svg)</strong>, porque es vectorial y no se pixela al ampliarlo.</p>
  <img src="descargas/icono.svg" alt="Icono vectorial en SVG" style="width: 100px;">

  <p>Para una animación corta tipo meme el formato recomendado es
  <strong>GIF (.gif)</strong> (o también APNG), porque permite animaciones.</p>
  <img src="descargas/meme.gif" alt="Meme animado en GIF" style="width: 200px;">

  <p>Para el icono de la pestaña del navegador (favicon) el formato recomendado es
  <strong>ICO (.ico)</strong>.</p>
</body>
</html>
```
