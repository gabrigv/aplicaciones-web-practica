# B1. Galería de tu setup

## Codigo

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>B1 Galeria de mi setup</title>
</head>
<body>
    <h1>Galeria de mi setup</h1>

    <h2>1. Tamaño original</h2>
    <img src="descargas/setup.jpg" alt="mi setup de escritorio">

    <h2>2. 200x150 con el atributo style</h2>
    <img src="descargas/setup.jpg" alt="mi setup de escritorio" style="width: 200px; height: 150px;">

    <h2>3. 200x150 con los atributos width y height</h2>
    <img src="descargas/setup.jpg" alt="mi setup de escritorio" width="200" height="150">

    <h2>4. Imagen rota a proposito</h2>
    <img src="descargas/setupp.jpg" alt="Mi setup de escritorio (imagen rota)">
</body>
</html>
```

## Pregunta: ¿Por qué se recomienda style frente a width y height?
Porque si la página usa una hoja de estilos CSS que cambia el tamaño de las imágenes, esa hoja tiene prioridad sobre los atributos width y height, y la imagen podría verse con otro tamaño. Con style el tamaño se respeta. Además, así se separa el contenido (HTML) del diseño (CSS).
