# A2. ¿Qué pasa al hacer clic?

- **Caso A:** El enlace `#precios` coincide con `id="precios"`, así que la página **salta al titular "Precios"**.
- **Caso B:** El enlace apunta a `#Precios` (con mayúscula) pero el id es `precios`. Como no coinciden, **no salta a ningún sitio**: la página se queda donde está.
- **Caso C:** Se abre la página **guia.html** y el navegador baja directamente hasta el elemento con `id="instalacion"`. Si ese id no existiera, se abriría guia.html al principio.
